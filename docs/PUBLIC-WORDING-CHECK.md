## What this is and is not

It inventories the shipped English default copy and the starter text a fresh `content init` writes. It does not cover campaign-authored overrides, private data, a deployed organizer site or any legal compliance question. It is not legal advice, not an accuracy certification and not a claim that any publisher follows it. A `partly` or `absent` row is an observation about the shipped copy, not an instruction to change it.

Verdict meanings:

- `present`: the whole wording pattern is evidenced in the audited surfaces.
- `partly`: some elements are evidenced, or the only evidence is on a conditional surface (an optional setting, a starter that an organizer must edit, a California-only answer).
- `absent`: no matching wording found in the declared corpus. A missing literal phrase alone is not treated as proof that the idea is missing; each row says what the nearest existing text is.

Summary: S2 is `present`; every other row (P1 to P10, S1 and S3 to S8) is `partly`. No row is `absent` as a whole, but several elements inside rows are (named in each row's "Missing or conditional" cell).

Excluded: organizer-supplied data and text (site.json, findings, agency profiles, map snapshots, `labels.json` overrides), generated JSON/CSV/feeds, the private meeting handout strings at `labels.py:364-375`, comments and docstrings, and CSS and script logic that carries no public wording.

Conditions that change what a reader sees:

- Preview versus content site: with no `content/` the build renders only `preview` (`site.py:335-349`), whose copy is fixed English with no counts and no dates (`site.py:343-346`). The content site uses `labels.py` keys.
- California versus other states: a California init keeps the draft FAQ's one law-package answer (`examples/faq.json:21-23`); another state gets generic wording without a rule id (`content_init.py:28-29,60-63`). `examples/pages/background.json` is written for California regardless of state (`background.json:4`).
- Starters carry `[EDIT ME: ...]` placeholders on every sentence (`content_init.py:22`) and are published by the next build until edited or deleted (`content_init.py:115`). They are draft text, not reviewed campaign output.
- A configured contact address adds separate `Correction request` and `Copyright notice` mailto subjects in the two fixed sections (`corrections_policy.py`, `policy_html`); without it both reuse the no-address sentence. A map snapshot with or without a date changes the map line (`labels.py:280`, `site.py:1205-1208`). Map, portal, sharing and action blocks render only when an organizer supplies the data.
- Features described in other open work items (answer fields, asked-item fields, legal-claim linting) are not part of this base and are not credited here.

## Appendix: scoped risk and count inventory

### Method

All of `labels.py` and the render contexts in `site.py` were read. Searches were case-insensitive over the 13 declared paths for the stems `operat` and `secret`, the phrases `there is/are/were/have been`, count placeholders (`{count}`, `{total}`, `{reported}`, `{mapped}`, `{spoke}`, `{written}`, `{shown}`), digits, number words and quantifiers (all, every, many, at least). Python string joins and JSON body strings were read as joined text. The search is only a discovery aid: constructions such as "Cameras: {count}" or a count formatted in Python have no number-before-noun form, so they were found by reading, not by pattern. A zero below means none found in the declared corpus, not none anywhere.

## Limitations

- The comparison is by one reader on one commit. Verdicts are judgments against the definitions above and can reasonably be argued differently.
- Only shipped defaults and starters were read. A campaign that supplies its own `labels.json`, site.json text, agency profiles or pages can read differently, better or worse; this document says nothing about any live site.
- Research observations are historical (2026-11-09). They are not evidence about what those campaigns publish today, and counts quoted by them are not repeated here as facts.
- Several rows depend on optional data (map snapshot, portal snapshot, contact address, starters). `partly` is used where the wording exists only on such a surface.
- This is a list. It proposes no replacement wording, ranking or fix, and a `partly` or `absent` row is not an instruction to change software.
