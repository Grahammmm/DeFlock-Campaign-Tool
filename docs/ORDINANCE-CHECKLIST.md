# Draft ordinance reading aid

This is a **draft reading aid**. It is **not legal advice** and it is **not a law package**: no tool reads it, nothing checks a draft against it, and it changes no review status in [LAW-PACKAGES.md](LAW-PACKAGES.md). It helps an organizer read a proposed local surveillance-technology or ALPR oversight ordinance by asking neutral questions, each tied to a provision some California city or county has enacted.

The examples are jurisdiction-specific. They are not California-wide requirements, and the cities named are not models to copy. Scope, definitions, exceptions, later amendments and how a provision applies to a particular proposal need qualified review (see [REVIEW-GUIDE.md](REVIEW-GUIDE.md) for who reviews what).

## How to use this

1. Find the language in the proposed draft that deals with the element.
2. Ask the question. Write down the draft's section number and anything you are unsure of as two separate notes.
3. Read the cited enacted provision in context, including its exceptions, before you rely on the paraphrase here.
4. Check the effective date and current text with the jurisdiction's clerk; [LAW-PACKAGES.md](LAW-PACKAGES.md#effective-date-discipline) explains why the date a rule took effect matters.

There is no score and no pass or fail. A draft that lacks an element is a question to raise, not proof of a defect. Several examples below cover surveillance technology in general; only Berkeley, Davis and San Francisco name automatic license plate readers in their definitions.

## Source notes

- Berkeley: the City's own code page links to berkeley.municipal.codes. That site's disclaimer says the City Clerk has the official version.
- Davis: the City's Municipal Code page embeds eCode360 for Davis. The Davis rows link the Article 26.07 page; the section and subsection are in the Citation column.
- San Francisco: sf.gov names American Legal Publishing as the official publisher of the Administrative Code.
- Checked 2026-11-04 against the pages linked above. A paraphrase here may be out of date after later amendments; the linked code governs.

## Subjects left out

Oakland (Municipal Code ch. 9.64) and Santa Clara County (Ordinance Code div. A40) were not cited because their official code pages could not be read when this was written. Renewal or sunset is not a row: no cited chapter above states one. An independent-audit requirement is not a row either; the oversight row only records that Davis lets a use policy name an independent oversight person or entity.
