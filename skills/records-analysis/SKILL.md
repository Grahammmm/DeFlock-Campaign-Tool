# Records analysis

Use campaign configuration and private storage, never hardcoded campaign hosts.
Read ../../docs/DATA-HANDLING.md for data boundaries. Keep exact receipt and hash
identities; a portal link alone is not an acquired record.

Inventory pages, sheets, attachments, redactions, hidden content and extraction
failures. Read originals alongside extraction. Store a digest with precise locators,
scope, actors, dates, duties, statements, omissions and counterevidence.

Determine event-date primary rules and local policy versions before comparison.
Separate documented_fact, apparent_conflict, confirmed_conflict, information_gap,
redaction, agency_assertion and no_conflict. The last label is bounded to the
tested proposition, never certification of an entire agency.

Blank/N/A exported values describe the export unless native semantics establish
more. Do not assume missing exhibits prove access or misconduct. Prepare targeted
follow-ups for missing schemas, scope, exceptions or records.

Output private digest, coverage ledger, evidence-to-duty matrix and proposed public
wording separately. Request independent factual, legal and privacy review. Extraction
does not count as substantive review. External sends and publication require scoped
authorization. A denied access path is a blocker, not permission to switch identities.

Stop after bounded retries on denied/expired inputs and record exact missing coverage.
No requirement for a specific model provider or proprietary entitlement.
