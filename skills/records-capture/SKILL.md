# Records Capture

Read the common contract and **Capture** stage before acquiring bytes. Verify the approved source, pinned acquisition implementation, private output and single writer. Capture through the supported local drop or mail adapter; retain exact bytes, acquisition receipt and distinct occurrences. A copied file is a local capture, not a fabricated mail delivery. A portal notice without bytes remains a retrieval hold.

Use existing acquisition limits and checkpoints. Do not expand permitted formats, roots, credentials or schedules through this skill. Stop on denied access, changed bytes or ambiguous identity. Hand off the private capture receipt to `records-preservation`; report acquisition counts separately from preservation acceptance.

Shared versioned inputs, outputs, retry/failure rules and Hermes release gates:
[Records stage handoff](../../docs/RECORDS-STAGE-HANDOFF.md). Read it for this stage;
use the next skill only after its eligibility conditions are satisfied. These
repository skills require that shared document to travel with the skill bundle.
