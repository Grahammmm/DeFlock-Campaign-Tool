# Records Applicability

Read the common contract and **Applicability** stage. Bind each proposition to a concrete conduct, disclosure, receipt or retention event as appropriate. Use official primary rule text and evidenced agency policy versions; record jurisdiction, regulated role, adoption, effective dates, exceptions and contrary evidence. Unknown dates or historical versions require a hold, not a silent default to today.

Use the installed comparison interface only for its supported scope. Context/revision integration is a separate source seam; do not invent fields in strict content/receipt schemas. Changed rules or event context require downstream invalidation and renewed exact-content approvals.

Keep facts, agency assertions, information gaps and apparent/confirmed conflicts distinct. Obtain independent legal review of material conclusions. Pass qualified sanitized propositions to `records-publication`; new evidence gaps may loop back to `records-correspondence`.

Shared versioned inputs, outputs, retry/failure rules and Hermes release gates:
[Records stage handoff](../../docs/RECORDS-STAGE-HANDOFF.md). Read it for this stage;
use the next skill only after its eligibility conditions are satisfied. These
repository skills require that shared document to travel with the skill bundle.
